STEP 2 - Create the website repository
  Click "+" (top right) > "New repository"
  Repository name: muhammadawaisrustam.github.io   (your username + .github.io)
  Public > "Create repository"

STEP 3 - Upload the website
  On the new repository page click "uploading an existing file".
  Unzip this folder, then drag EVERYTHING inside it into the upload box
  (index.html, admin.html, content.json, render.js, site.css, images folder, etc.)
  Click "Commit changes".

STEP 4 - Turn the website on

  Source: "Deploy from a branch"  Branch: "main"  Folder: "/ (root)"  > Save

STEP 5 - Connect the dashboard (so the Publish button works)
  Open https://muhammadawaisrustam.github.io/admin.html
  Go to "Connect & backup" and follow the 5 steps shown there to create an
  access token (GitHub > Settings > Developer settings > Fine-grained tokens,
  only your website repository, Contents: Read and write).
  Paste it and press "Save & test connection".
